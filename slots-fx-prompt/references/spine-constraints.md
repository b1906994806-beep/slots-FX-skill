# Spine 落地约束规则

**适用条件：** STEP 1.3 选择 [S] Spine 骨骼动画时加载，全流程生效。

**核心原则：** 提示词描述的动效必须在 Spine 骨骼系统内可实现，确保参考视频对动画师具有实际落地价值。

---

## 禁止推荐的动效类型

| 禁止项 | 原因 |
|--------|------|
| 大幅转面（视角变化 > 30°） | 需要多套不同角度美术资产，骨骼无法自动生成 |
| 3D 透视缩短 / 透视变形 | 2D 骨骼系统无法模拟 3D 空间透视 |
| 复杂布料完整物理模拟 | Spine 物理有限，复杂布料需专业工具 |
| 细腻面部表情变化 | 需专门制作 Mesh 变形资产，成本高 |
| 大范围形态重构（如液体变形、融合） | 超出骨骼系统能力范围 |
| 复杂粒子爆发（大量密集粒子群） | Spine 粒子系统有限，建议拆为独立特效层 |

---

## 优先推荐的动效类型（Spine 擅长）

| 推荐项 | Spine 实现方式 |
|--------|--------------|
| 位移入场 / 出场 | 骨骼 Translate 动画 |
| 旋转摆动（尾巴 / 肢体 / 道具） | 骨骼 Rotate 动画 |
| 呼吸起伏 / 脉动缩放 | 骨骼 Scale 动画 |
| 透明度渐变 / 淡入淡出 | Slot Alpha 动画 |
| 颜色变化 / 发光脉冲 | Slot Color 动画 + Additive Blend Mode |
| 弹性缩放 / 卡通回弹 | Scale 关键帧曲线调节 |
| 简单粒子（少量光点 / 星光） | Spine 粒子系统 |
| 布料轻微飘动（发丝 / 披风边缘） | Spine 物理约束（IK / Physics） |

---

## 人物 / 角色类专属约束

> 适用于 STEP 3B-3c 识别到核心素材为"人物/神明/英雄"时自动附加。

- **固定视角原则**：角色保持原图视角（正面 / 3/4 侧面），禁止推荐超过 30° 的转面动作
- **动作范围约束**：以骨骼旋转为主，避免需要多角度资产的大幅体态变化
- **表情约束**：眼部微亮、眨眼等简单变化可用；复杂表情变化（皱眉、大幅嘴型变化）需提示"需额外 Mesh 资产"
- **实时生成推荐时**，必须在方案描述末尾附加：
  > ⚠️ Spine 参考：以上动效保持原图视角，骨骼位移/旋转/缩放可落地，请避免大幅转面实现。

---

## STEP 4 方案预览约束

Spine 模式下，方案预览自动过滤以下方向：
- 包含大幅转面 / 视角切换的方案
- 依赖 3D 透视的运镜方案
- 需要复杂粒子群的爆发方案（可保留，但须注明"建议拆为独立特效层"）

---

## 输出提示词末尾附加说明

Spine 模式下，每条提示词生成后，在约束语之后追加一行：

```
【Spine 参考说明】以上动效基于 Spine 骨骼系统可落地范围设计，固定视角，动作以位移/旋转/缩放/颜色为主。
```
