# STEP 4：方案预览（Pre-generation Scheme Preview）

输出 2–3 个差异明确的候选方案，用户确认后再生成完整提示词。

---

## 4-1 配置项

### 动效方向（必选）
- **[A]** 轻量待机
- **[B]** 冲击爆发
- **[C]** 元素表现
- **[D]** 生物感
- **[E]** 对抗演出
- **[F]** 自定义关键词（用户自由描述，Skill 自动归类）

### 表现强度（可缺省，默认 B 中）
- **[A]** 轻 — 适合常驻 UI，不抢画面
- **[B]** 中 — 有明显演出感，适合大多数 Slots 图标（默认）
- **[C]** 强 — 冲击更足，适合出现、触发、大奖感
- **[ABC] 批量全档** — 一次输出轻/中/强三档变体

### 预览形式（可缺省，默认 B 半结构）
- **[A]** 一句话预览
- **[B]** 半结构预览（默认）
- **[C]** 详细预览

### 可选补充
主体（文字/动物/文字+动物）/ 类型（出现/待机/转场）/ 限制（不要缩放/不要位移/不要镜头/简单循环）/
风格（写实/神兽/夸张/高级感/爆发型）/ **排除（不要抖动/不要金币/不要闪烁/不要复杂特效/用户自由描述）**

---

## 4-2 默认规则

- 未指定**表现强度** → 自动使用 **[B] 中**
- 未指定**预览形式** → 自动使用 **[B] 半结构预览**
- 未补充主体/类型/限制/风格 → 优先根据上下文自动推断，不主动追问
- 唯一例外：主体信息缺失且明显影响方案输出时，补问 **1 个**最关键问题

### 动效方向偏置映射（内部使用）

| 动效方向 | 动作结构偏置 | 节奏类型偏置 | 视觉重心偏置 | 光效层级偏置 |
|---------|------------|------------|------------|------------|

## 4-4 方案预览输出规则

- 从差异维度中选取 2–3 个，方案间**动作结构、节奏感或视觉重心**必须有明显差异，禁止同义换词
- 排除项作硬性约束，规避所有候选方案中的指定元素

**预览格式：**
- **[A] 一句话**：`方案名 — 核心动效一句话`
- **[B] 半结构（默认）**：`方案名 / 动作核心 / 光效节奏 / 整体感受`
- **[C] 详细**：`方案名 / 动作核心（含部位因果链）/ 光效节奏 / 文字联动 / 整体感受`
- **[ABC] 批量全档**：直接输出轻/中/强三档（均用半结构格式），询问：`[轻] [中] [强] [全部生成] [调整方向]`

---

## 4-5 用户确认

预览输出后询问：`[1]方案一 [2]方案二 [3]方案三 [再来几个] [微调方案X]`

- 选定方案 → 生成完整提示词（按模式/场景路由至对应模板，同时读取 `style-profiles.md` + `compliance.md`），完成后执行 **4-6 验证**
- 再来几个 → 重新生成 2–3 个新方案
- 微调 → 调整后再次预览

---

## 4-6 生成后自动验证（内部执行，不向用户展示检查过程）

**触发时机：** 完整提示词生成完毕后、向用户输出前，必须执行此验证。

**执行方式：** AI 内部逐项检查，不向用户输出"正在验证…"等中间过程。  
- 全部通过 → 直接输出最终提示词，无需提示用户  
- 任意一项失败 → 按失败处理规则处理，不得悄悄修改后直接输出

### 检查清单

| # | 检查项 | 适用范围 | 失败判据 |
|---|--------|---------|---------|
| V1 | Idle 无缝循环声明 | 所有 Idle 状态 | 提示词中未出现"无缝循环"或等价表述 |
| V2 | 禁止镜头运动 | 所有 Scene A（图标）| 提示词含镜头推拉、摇移、缩放等描述 |
| V3 | 禁止大幅位移 | 所有 Scene A（图标）| 提示词含大幅移动、飞出画面、大范围位移等描述 |
| V4 | 动作描述非模糊 | 所有主体动作段 | 在主体动作描述段（非闭合约束行）出现"剧烈运动""动感十足""充满活力"等**无部位、无因果链**的模糊表达作为主要动作描述 |
| V5 | Vidu 末尾参数 | tool = Vidu Q2 或 Both | 提示词末尾未标注 `小幅动态` / `中等动态` / `大动态` 其中之一（官方中文动态词） |
| V6 | Seedance 开头锚定 | tool = Seedance 2.0 或 Both | 提示词未以 `@图片1的[特征]，` 开头（意图[D]时：@图片1 + @图片2 均需出现）|
| V7 | Seedance 末尾约束段 | tool = Seedance 2.0 或 Both | 提示词末尾未附加显式约束语 |
| V8 | 合规禁用词 | 所有输出 | 出现 compliance.md 中任意禁用词（jackpot/slots/win 等） |
| V9 | 弹窗/加载页层级优先级 | Scene B / Scene C | 提示词描述违反信息层级（如背景粒子覆盖标题、Logo 未最后稳定） |

### 失败处理规则

**V1–V4（动效规则类）失败：**
```
[验证提示] 生成内容有一处需要调整，正在修正…
```
AI 自行重写违规段落，重新执行 4-6 验证，通过后输出。若二次仍失败，输出提示词并注明：
```
⚠️ 注意：[具体问题描述]，建议手动检查该段表述。
```

**V5–V7（格式类）失败：**
AI 直接补全缺失的格式元素（末尾参数 / 开头锚定 / 约束段），无需提示用户，重新执行 4-6 验证。

**V8（合规类）失败：**
AI 按 `compliance.md` 替换词表自动替换，无需提示用户，重新执行 4-6 验证。

**V9（层级优先级类）失败：**
```
[验证提示] 生成内容有一处需要调整，正在修正…
```
AI 调整违规层级描述后重新执行 4-6 验证。若二次仍失败，标注警告后输出。
