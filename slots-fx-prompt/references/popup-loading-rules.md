# 弹窗、转场、加载页动效规则

## Popup Motion Rules

### Trigger Popup — Entry（触发弹窗入场）
- 面板以缓动方式滑入/缩放入（非瞬间弹出）
- 面板稳定后主体入场动作
- 粒子跟随主体入场
- 标题最后弹出或扫入
- 入场末尾增强爆发

### Trigger Popup — Idle（触发弹窗待机）
- 面板边框持续柔和光晕
- 主体轻微呼吸微动
- 粒子缓慢漂移
- 高光触发：每 8–10 秒

### Settlement Popup — Entry（结算弹窗入场）
- 面板伴随能量扩散出现
- 奖励主体显著入场动作
- 数字向上滚动
- 金币雨或粒子爆发
- 胜利标题扫入带发光

### Settlement Popup — Idle（结算弹窗待机）
- 数字柔和发光
- 金币缓慢漂浮 / 宝石轻柔闪烁
- 大气光晕脉冲
- 高光触发：每 8–10 秒

## 弹窗信息层级优先级

弹窗中多个视觉层同时运动时，演出资源按以下优先级分配。**高层级元素必须最后收束（即停留时间最长、最后稳定）；低层级元素只做配衬，不得超越高层级的视觉强度。**

| 优先级 | 元素 | 演出原则 |
|-------|------|---------|
| ① 最高 | 标题文字 / 大奖金额数字 | 最后出现或最后稳定；字体清晰可读；光效托高不遮挡 |
| ② 高 | 主体角色 / 核心奖励物 | 运动幅度最大；入场早于文字，但峰值不压过标题 |
| ③ 中 | 主体装饰粒子 / 能量环 | 跟随主体；消散在文字稳定之前 |
| ④ 低 | 背景粒子 / 环境光效 | 最先出现、最先衰减；强度不超过主体粒子的 50% |

**违禁模式：** 背景特效覆盖标题区域 / 粒子遮挡数字 / 多层同时峰值（导致视觉过载）

### Popup Motion Hard Restrictions
- 面板边界必须清晰（不溢出）
- 文字/数字任何时候保持可读
- 弹窗动画内无硬切
- 循环状态必须无缝循环
- 禁止快速闪烁或频闪

## Transition Motion Rules

### Custom Transition（独立转场 IN / OUT）
- 能量从中心或边缘积蓄
- 光束扫过全屏
- 粒子传递动势
- 场景切换隐藏在能量峰值时刻

### Universal Transition（Scatter 为中心的通用转场）
- Scatter 图标出现在画面中心作为视觉锚点
- 能量从 Scatter 图标向外辐射
- 光环扩散并消散
- 转场发生在扩散峰值
- 进/退场使用相同设计（反向时序）

### Transition Hard Restrictions
- 转场必须沉浸流畅
- 禁止硬切或突然跳跃
- 玩家必须感受到连续空间流动
- 时长：1.5–3 秒

## Loading Screen Motion Rules

### One-shot Mode（单次播放）
- 背景从暗逐渐变亮
- 主体以清晰的入场动作进入
- Logo 最后出现并突出强调
- 末尾有清晰的完成感
- 时长：3–5 秒

### Loop Mode（循环播放）
- 所有元素持续轻柔运动
- 大气效果缓慢呼吸
- Logo 轻微脉冲或发光循环
- 无缝循环，无可见重启点

---

## 加载页信息层级优先级

游戏 Logo 是最终视觉锚点，必须最后稳定且最清晰。

| 优先级 | 元素 | 演出原则 |
|-------|------|---------|
| ① 最高 | 游戏 Logo / 品牌标题 | 最后入场或最后稳定；出现后不再运动（仅允许轻脉冲） |
| ② 高 | 主体角色 / 核心图像 | 入场动作最具冲击力；Logo 出现前已完成主运动弧线 |
| ③ 中 | 主体光效 / 能量粒子 | 随主体消散，Logo 出现时必须已衰减至低强度 |
| ④ 低 | 背景环境 / 大气粒子 | 全程低强度；不得遮挡主体或 Logo 区域 |

**违禁模式：** Logo 被背景粒子遮挡 / 主体运动与 Logo 出现同时峰值 / 循环模式中 Logo 强烈闪烁
