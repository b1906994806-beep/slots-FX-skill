# 动效规则：图标各级 & 主体专项动作规则库

## Icon Motion Rules

### Level 1 — Low-tier Symbols（Win only，最小动效）
- 中奖时简单光晕脉冲
- 单次粒子爆发（1–2 个金币闪烁）
- 无身体运动，无旋转
- 时长：1–2 秒

### Level 2 — High-tier Symbols（Win only，中等动效）
- 中奖时中等光晕扩张
- 轻微能量环波纹
- 小型粒子爆发（金币/宝石）
- 时长：1.5–2.5 秒

### Level 3 — Special Symbols（Wild/Scatter/Bonus，完整状态集）

**Idle 待机：**
- 持续细微呼吸/漂浮
- 柔和光晕流动或能量环缓慢旋转
- 必须无缝循环
- 高光触发：每 8–10 秒，短暂增强 0.5–1.0 秒

**Land 落定（转轴停稳时）：**
> Land 定义：不是位移下落，而是符号停稳时的短促能量爆发（0.3–0.5s），强调玩家注意。
- 落地时短促冲击脉冲
- 快速能量闪光后稳定
- 时长：0.5–1.0 秒

**Win 中奖：**
- 全力能量释放，动态扩张
- 粒子爆发（金币/闪电/宝石）
- 主体必须有明确的身体动作（见下方规则库）
- 时长：2–4 秒

**Anticipation 期待抖动（仅 Scatter）：**
- 节律性细微振动，等待中
- 预期光晕脉冲
- 不释放完整动画
- 时长：循环直到触发解决

## 主体专项动作规则库（中奖状态）

### 动物主体（虎/狮/龙/狼/鹰等）
- **头部**：猛力向前冲向镜头，或仰起嘶吼
- **下颌**：猛然张开，獠牙/牙齿清晰显露，序列：闭合 → 张开
- **眼睛**：收缩（张力）→ 骤然迸发，带峰值发光/颜色爆闪
- **耳朵**：向后紧贴头骨（攻击）或向前竖起（警觉）
- **面部毛发/鬃毛**：向外炸开，明显扩散
- **胡须（如有）**：张开，随能量振动
- **颈部肌肉**：冲击时可见紧绷隆起
- **身体**：轻微前冲/突进（小幅度，无大位移）
- **尾巴（如可见）**：猛烈甩动一次

### 角色主体（人物/战士/神祇/法师等）
- **表情**：平静/沉稳 → 凶猛/得意/喜悦（匹配游戏主题）
- **眼睛**：睁大或发光增强
- **嘴巴**：张开战吼，或大笑
- **上身**：挺直并略微前倾，胸部扩张
- **手臂/武器**：举起武器向上，或双臂向外展开成力量姿态
- **头发/斗篷**：随能量向外流动或激涌

### 宝石/水晶主体
- **旋转**：绕竖轴旋转（循环安全时完整360°，Win 爆发时180°冲击）
- **缩放**：脉冲扩张 1.0 → 1.15 → 1.0
- **切面**：各切面依序快速闪光（级联闪光效果）
- **内部发光**：核心亮度从暗 → 峰值 → 收束

### 金币主体
- **翻转**：金币向前翻转（正面显现）
- **缩放**：快速弹跳缩放 1.0 → 1.2 → 1.0
- **高光**：高光条划过金币表面

### 骰子主体
- **旋转**：在某一轴上完整平滑旋转 360°
- **归位**：精确回到原始朝向（循环安全）
- **冲击**：落定时轻微弹跳

### 卡牌主体
- **展开**：从叠合位置扇形展开，清晰显示层次
- **闪光**：每张牌边缘依序捕光
- **归拢**：牌回到近叠合位置（循环用）

### 机械/装置主体
- **旋转**：旋转元素加速后减速
- **能量**：能量核心变亮，指示灯依序激活
- **振动**：能量峰值时轻微快速抖动

## 图标动效硬性约束（始终生效）

- 禁止身体转向或旋转
- 禁止朝向变换
- 禁止大幅位移或位置变化
- 禁止镜头运动/剪切/缩放
- 禁止快速闪烁或剧烈运动
- 所有 Idle 状态必须无缝循环
